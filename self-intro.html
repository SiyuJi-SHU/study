2完整回答

面试官好，我是纪思羽，上海大学电子信息硕士，2027 届，求职方向是 AI 应用开发，主线是 Agent、RAG 和评测。

Agent 侧，用 Spring AI Alibaba 做过意图路由、Function Calling 和结构化输出，落地 ReAct、Plan-Execute-Replan、Supervisor-Worker 三种执行模式。RAG 侧做过结构感知切分、Milvus 向量加 Lucene BM25 双路召回、RRF 融合、Rerank 精排和引用溯源。评测侧用 Hit@K、MRR、证据覆盖率分层指标，加人工校验和 LLM-as-a-Judge，把失败定位到具体环节。

实习在复星数智化与 AI 条线，做 Dify 应用部署、功能迭代和 UAT 验收，也做模型 API 兼容性、并发与时延评测，核心是把 AI 应用跑通并给出可验收结论。

把这些实践沉淀成 Totoro Nexus 可配置 Agent 与知识库评测平台，两个关键设计：一是 Agent 行为配置化、版本化，模型、知识范围、工具权限、执行模式都变数据，行为可追溯；二是检索命中后回不可变原文按 offset 扩窗、程序回填引用，解决答案跨 Chunk、证据不完整。

科研有一篇 IEEE TIM 一作在审，自建 FEB-Bench、提出 Edge2Me，只训练 3.51% 参数完成跨成像条件域适配。希望把这些能力用在真实业务场景。
