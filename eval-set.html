评测集怎么构建

1一句话和流程
一句话

生成 → 三层校验 → 坏题过滤 → 版本绑定 → 人工金标准

2完整回答

先按 Chunk 生成候选：把 Chunk、文档标题、上下文给模型，产出问题、参考答案和证据位置，证据必须带文档 ID、版本和起止位置。

然后三层校验。第一层回原文核对，答案和证据必须在对应版本找到，位置对得上；第二层用另一个模型复核，判断问题可不可答、答案是否被证据支持、有没有泄漏；第三层人工确认，至少抽样，争议题直接剔除。

生成时过滤坏题：答案不唯一、依赖外部知识、太模糊、证据跨太多块的都不进题集。生成模型和被测 Agent 分开，参考答案不能进被测上下文。

题集绑定知识版本、Agent 版本、检索配置，资料更新后旧题重新校验或标记失效。

边界：自动生成只出候选，人工确认才是金标准，题集规模也不代表全覆盖。

3可能被追问
  • 参考答案会进被测上下文吗？→ 不会，生成模型和被测 Agent 分开。
  • 资料更新了旧题怎么办？→ 题集绑版本，旧题重新校验或标记失效。
  • 怎么保证生成题不是错的？→ 三层校验，最后人工抽社保底，争议题剔除。
缺口

金标准是人工不是模型，这句是边界，别把"自动生成"说成"全自动"。
