总管问

讲讲你在复星的实习，具体做了什么？

我在复星数智化与 AI 条线做 AI 开发实习，主要三件事。

一是乡村医生助手，基于 Dify 做的，这个项目我从头跟到尾。它分两块，Agent 和应用。Agent 这块是我搭的：在 Dify 上做应用编排、建知识库、配工作流，模型和 Prompt 也是我在上面调的。应用这块有管理后台和聊天端，功能迭代我前后端都做。举个例子，地域看板加四个 Excel 导出，从接口到页面到导出文件都是我做的，本机跑测试和类型检查，再上 UAT 验，最后走 GitLab 到 Jenkins 发布，有问题就回退。

二是用 EvalScope 测云厂商的模型 API，阿里百炼、火山引擎、华为云这三家，测并发、时延和吞吐，给企业大模型私有化部署选型提供建议。

三是复星对接的一个企业级 Agent SaaS 产品，前端、后端都可以自主配置 Agent。我在对它的接入与评测过程中，对完整的企业级 Agent 形态有一定了解。

被追问时的回答

问答效果不好，你先查哪里？我不先怪模型，按四层从上往下看：知识库的文档质量和切分、检索有没有召回、Prompt 和上下文、入口和权限。Dify 侧用命中测试和问答日志定位，必要时补测试问题、人工抽检。

Dify 是现成的，你的技术含量在哪？Dify 只是个底座，用它就像用 Spring Boot 一样，产品是我在上面做出来的。Agent 的编排、知识库、工作流怎么设计是我的事，应用的前后端功能是我写的，效果不好也是我来定位。

你改过 Dify 源码吗？没有，也不需要。它的编排能力够用，我的工作是在上面把 Agent 和应用搭出来。
