Totoro 这个项目，你为什么要自己做？

因为我想展示我个人对于整个 Harness 的理解。因为 Harness 无非就是包括一个完整的 agent loop，里面会加入各种各样的工程化思想。这些东西光看别人做是不够的，所以我从零做了这个完整的项目，把它走了一遍：

一是上下文管理；

二是意图识别；

三是整个后端能够自主配置 Agent、自主创建知识库；

四是完整的评测链路。

这四块不是照着教程搭的，是我自己设计的。Agent 跑一次的整个生命周期，用哪个版本、哪些资料、哪些工具、花多少预算，都由一个 AgentRuntime 统一管；每次运行从头到尾都落在 PostgreSQL 里，答错了能追到是哪一步、用的哪个版本。所以它不是一个只能跑的 demo，是一个能追溯、能复现、能评测的完整系统。

这个链路我非常感兴趣，也觉得很新颖，因为我觉得它能够实际在我的生活中对我产生帮助。所以我结合现今 AI 强大的编程能力，只要我能够在整个架构上把 Agent 的各个模块吃透，就能够构建出完整的一个项目。基于此，我就实际动手去开发这个项目，这个项目是我从零开始全栈开发的，从架构到后端到评测，都是我一个人做的。
