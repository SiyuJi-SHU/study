Totoro 这个项目，你为什么要自己做？

因为我想展示我个人对于整个 Harness 的理解。因为 Harness 无非就是包括一个完整的 agent loop，里面会加入各种各样的工程化思想。所以我从零做了这个完整的项目，把它走了一遍：

一是上下文管理；

二是意图识别；

三是整个后端能够自主配置 Agent、自主创建知识库；

四是完整的评测链路。

这四块都是我自己设计的。比如 Agent 跑一次，用哪个版本、哪些资料、哪些工具、花多少预算，都是 AgentRuntime 管的；每次运行都落在 PostgreSQL 里，所以答错了，我能查到是哪一次运行、用的哪个版本、检索到了什么。

我对这个链路很感兴趣，它在我生活里也确实用得上。现在 AI 写代码的能力很强，只要我把 Agent 的各个模块搞清楚，就能把整个项目做出来。所以我就动手做了，从零开始全栈开发，从架构到后端到评测都是我一个人做的。
