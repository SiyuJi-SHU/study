④Totoro Nexus全场最重的一段

所以我自己也开发了 Totoro Nexus，这是一个可自主配置知识库与 Agent 的平台。里面已经上线了一个运维 Agent，还有我用来读书籍论文的 Agent，以及问答类型的一整套 Agent。

这个 Agent 里面所有的 Harness，也就是整个链路，都是我设计的：工具集、意图识别、上下文管理、行为模式，全都是我个人设计的。也做了完整的评测，包括 RAG 评测和 Agent 评测。RAG 评测就是一些常见的指标，都是我自己结合最新的技术栈去落实的；Agent 评测是基于 LLM-as-a-Judge 以及人工校验来完成的，整套链路闭环都是我做的。

这个项目是基于 Spring AI、Docker，还有 Milvus 这些框架来搭建的，调的大模型是阿里百炼的 DashScope。

⑤科研收尾

最后是我的科研经历，做的是视觉模型的微调，用 PEFT 的方法，把通用的视觉能力微调到工业光纤端面的高精度几何参数测量上，用来解决传统光纤端面测量算法中，遇到污点干扰时会失效、鲁棒性不够高的情况。

可选收尾
