你了解我们吗？为什么想来宇量昇？

讲稿四个原因

我了解到宇量昇是一家国资控股的公司，2022 年成立，在上海浦东，做的是半导体行业的高精尖装备研发。我想来主要有四个原因。

第一是行业。半导体装备是国内正在重点补的一块，软件在这里是产品的一部分，我想进到这个方向里去。

第二是岗位对口。我主要用的就是 Java 和 Python。这个岗位要从客户需求一直做到上线维护，我在复星做过应用的编排、UAT 测试到上线，自己的项目 Totoro 里做了运行回放和失败归因，出了问题能追到是哪一步。性能调优这块，我在复星测过三家云厂商大模型 API 的并发和时延。另外我有算法背景，科研做的就是工业测量算法。

第三是地点。公司就在上海浦东，我本硕都在上海。

第四是方向。二面的时候了解到，团队在用 DeepSeek Harness 做个人定制的 Agent。这块我自己做过：Totoro 整个 Harness 的链路是我自己设计的，工具集、意图识别、上下文管理、评测都走了一遍。开源的 Harness 我也一直在跟，Learn Claude Code 学了一半，DeepSeek Harness 我刚上手，官方教程已经跑通了第一章。所以这个方向我很想进来一起做。

查到的公司信息：

· 聚焦半导体行业高精尖装备研发的新型高科技企业，位于上海浦东（校招公告原文）

· 国资控股，2022 年 7 月成立，注册资本 10 亿元

· 校招类别：光学光电、机械机电、软件算法、电子电气、环境控制、集成工艺与材料、制造

· 岗位分三个方向：产品软件、仿真软件、产品大数据

· 职责：从客户需求到产品定义、架构设计、开发实现、商用运营维护；参与需求分析，写详细设计文档并维护

· 要解决的技术难题：分布式系统、性能调优、可靠性、数据库等

· 要求：C++、Python、Java 会一种或几种；Qt 和数据库（大数据方向）；一面了解到团队实际用 Python 和 Java

· 专业：计算机、电子、通信、自动化；仿真方向写了有算法背景的优先
