s01 · Agent Loop

  • 加了什么：一个 while 循环 + 一个 bash 工具，30 行代码
  • 总结：s01 之前你自己就是 loop——复制命令、跑、贴结果。这章把人肉中转写成代码：模型说要执行什么，harness 执行、结果作为 tool_result 贴回 messages，模型不再要工具就退出。模型管决策，harness 管执行。每轮全量重发 messages，还没有任何上下文管理

注意：不是只发最新一条，是每轮全量重发。tool_calls 是模型这一轮想调的所有工具组成的列表，for 循环逐个执行。
